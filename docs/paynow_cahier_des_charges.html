PayNow
Cahier des charges & plan de travail
01 — Présentation du projet
Vision
PayNow est une passerelle de paiement (Payment Gateway) qui permet à tout développeur d'intégrer plusieurs méthodes de paiement via un bouton unique et une page de checkout hébergée.
Positionnement
Comme Stripe ou PayPal mais orienté marché international avec support natif Mobile Money africain (MVola, Airtel, Orange) + cartes internationales.
02 — Acteurs du système
Marchand
Développeur qui intègre PayNow dans son app via SDK + clé API
Client final
Utilisateur de l'app marchand qui effectue le paiement sur la page PayNow
Admin PayNow
Toi — gère les marchands, les providers, les commissions et les litiges
03 — Méthodes de paiement supportées
Visa / Mastercard MVola (Telma) Airtel Money Orange Money PayPal Virement bancaire Crypto (phase 3)

07 — Plan de travail — 8 phases
1
Setup & fondations
Semaine 1
Initialiser le projet Laravel + React + MySQL Configurer Tailwind avec la palette PayNow Créer les migrations : merchants, transactions, api_keys, webhooks Mettre en place Laravel Sanctum pour l'auth
2
Auth marchands + Dashboard
Semaine 2
Inscription / connexion marchand (React + API Laravel) Génération et gestion des clés API Dashboard marchand : stats basiques, profil Layout général avec thème PayNow
3
Page checkout PayNow
Semaine 3
Page checkout.paynow.com/pay/{token} Formulaire de saisie des infos de paiement Sélecteur de méthode (Carte, MVola, Airtel...) Pages de succès / échec / pending
4
Intégration Stripe (cartes)
Semaine 4
Créer le PaymentRouter Laravel Intégrer Stripe PHP SDK Gérer PaymentIntent, confirmation, remboursements Tester le flux complet end-to-end
5
Système Webhooks + Transactions
Semaine 5
Jobs Laravel pour l'envoi async des webhooks Retry automatique en cas d'échec (3 tentatives) Historique complet des transactions Reçu PDF téléchargeable
6
SDK JavaScript (npm package)
Semaine 6
Package npm paynow-js Bouton PayNow avec redirection Callback onSuccess / onError / onClose Documentation et page de démo
7
Mobile Money (MVola, Airtel, Orange)
Semaines 7–8
Intégrer MVola API (Telma) Intégrer Airtel Money API Intégrer Orange Money API Gestion des statuts async (polling + webhook)
8
Admin panel + sécurité + déploiement
Semaines 9–10
Panel admin : gestion marchands, litiges, stats globales Détection fraude : limites, alertes, blacklist Chiffrement des données sensibles (AES-256) Déploiement production + monitoring
08 — Exigences de sécurité
Obligatoires
HTTPS sur toutes les routes · Clés API hashées (SHA-256) · Tokens de transaction signés (JWT) · Validation HMAC des webhooks · Rate limiting API · Chiffrement données bancaires
Recommandées
2FA pour les marchands · Logs d'audit complets · IP whitelisting optionnel · Détection de doublons de transaction · Conformité PCI-DSS niveau 1
09 — Critères de succès (MVP)
Fonctionnel
Un marchand peut s'inscrire, obtenir une clé API et recevoir un premier paiement réel en moins de 15 minutes
Performance
Page checkout chargée en moins de 2s · Webhook envoyé en moins de 5s après confirmation
Fiabilité
Zéro transaction perdue · Retry webhook automatique · Logs de toutes les erreurs provider
